# Climb

**Know your level. Climb higher.**

An AI-powered IELTS practice platform for Writing and Speaking.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (Auth + Database + Storage)
- Anthropic Claude API (AI grading)

## Getting Started

1. Copy `.env.local` and fill in your keys
2. Run `npm install`
3. Run `npm run dev`
